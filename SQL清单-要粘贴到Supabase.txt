位置：Supabase → 左侧 SQL Editor → 新建 query → 整段粘贴 → Run，看到 Success 就行


【第 1 段】让后台能删除评价（评价返图管理要用）

grant delete on table public.reviews to authenticated;

drop policy if exists "reviews delete authed" on public.reviews;
create policy "reviews delete authed" on public.reviews
  for delete to authenticated using (true);


跑完之后：
1. 后台页面按 Cmd+Shift+R 强制刷新（或者完全关掉重开）
2. 后台 → 顶部页面切换器 → 评价返图（小铺上架页里也有「评价返图管理 →」按钮）
3. 每张评价卡下面就有「删除」；登录状态下前台小铺的评价卡右上角也有 ⋮ → 删除这条评价
