Google Maps 配色对比（改前 / D 方案）

左边是改前（道路 #F3DDE4、边界 #E6D3DA），右边是 D 方案（道路 #E0B9C8、边界 #CDB0BB）。 只差这两个颜色，陆地 / 水域 / 公园 / 文字一律不变。
这是配色预览页（不带 Map ID 的老式地图，所以 colors 数组能直接生效），不是美食地图本身。

正式美食地图用的是 Map ID（自定义粉色标记与聚合需要它），带 Map ID 时 Google 会忽略页面里的 colors 数组， 所以正式页面要变成 D 方案，需要在 Google Cloud Console 把这套 JSON 导入成 Map Style 并挂到现有 Map ID 上——不产生任何费用。
